# NOVA — demo online store

NOVA is a demonstration website for a premium audio shop: headphones, earbuds, speakers,
turntables, microphones and amplifiers. It has four pages — a home page, a catalogue, a
product page and a cart with checkout — and it looks and behaves like a real shop, but no
money changes hands and nothing is sent anywhere. Everything runs inside the visitor's own
browser, on their own machine.

There is nothing to install and nothing to build. The files you see are the whole website.
